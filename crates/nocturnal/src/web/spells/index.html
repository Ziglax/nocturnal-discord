How it works

The items

Spectral Parchment → random 63-64 spell. Glyphed Rune Word → random 65 spell. Each is handed to the class NPC in the Plane of Knowledge and rolls on that class's fixed pool (odds shown as 1/pool size). Pools are verified against pqdi.cc.

Setup

Dashboard: set the parchment/rune stock. Priorities: order the class cards (drag or rank number) and build each class's ordered spell list, with the copies wanted per spell. Class Weights: set the mains (M1 and M2) per class and the M2 weight ratio.

Phase 1: priorities

Every listed spell has a priority tier (P1, P2, ...) and a wanted-copy count; several spells of one class may share a tier and are secured together. A tier is fully served before the next one starts: round 1 secures one copy of each class's P1 spells (walking the class cards in order), the following rounds secure their remaining copies, and only then do the P2 spells start. Phase 1 ends when every listed spell has all its wanted copies.

Phase 2: fair share

Turn-ins are spread by (M1 + ratio × M2) × pool size (the class's 63-65 spell count: casters have bigger pools than hybrids; an M2 main counts at the configurable ratio, 50% by default). All logged turn-ins count, including phase 1's. Feed the class with the highest deficit.

Recording & duplicates

Follow the Dashboard queue and record each result in three clicks (item → class → spell); stock decrements automatically and requires stock in hand. Copies beyond a spell's wanted count, or repeats of unlisted spells, are flagged roll it: roll them off among mains in raid/Discord.

obtained* / dropped elsewhere: the same scroll came out of another class's pool (hover for details); a multiclass scroll can be handed to any class that scribes it. Tracking stays per class: if you allocate such a copy, lower that spell's wanted count.

Your data

In local mode everything lives in this browser (localStorage). Hosted behind Discord sign-in, the state is shared on the server: officers write, raiders read. Use Export/Import state to back up or hand over.
